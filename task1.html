2. Primitive vs. reference

A primitive holds its value directly; copying it copies the value. A reference (object/array/function) holds a pointer to the value in memory; copying it copies the pointer, not the contents.

Short answers

What is the difference between let and const?
Both are block-scoped. let can be reassigned later; const can't be reassigned after its initial value is set. const doesn't make objects immutable — you still can't reassign the variable itself, but you can still change properties inside an object it points to.
What does typeof null return?
This is a long-standing bug in JavaScript kept for backward compatibility — null is not actually an object.
What are JavaScript's primitive types?
string, number, boolean, undefined, null, symbol, and bigint. Everything else (objects, arrays, functions) is a reference type.

My notes

The trickiest part to remember is that typeof null === "object" — it looks like it should return "null". Also worth noting: undefined means a variable was declared but never given a value, while null is an explicit "this is intentionally empty" from the developer.
