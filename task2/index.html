Async Task Runner

A small closure-based task runner built with plain HTML, CSS and JavaScript to demonstrate the call stack, promises, async/await and the event loop.

1 · Tasks (closures)

Each task is created with createTask(name). The run counter is stored in a variable closed over inside the factory function — it can only be read through getCount(), never touched directly, so each task's counter is fully private and independent from the others.

2 · Sequential vs. Concurrent

Same three simulated loads (700ms, 900ms, 600ms). Sequential awaits each one before starting the next; concurrent starts all three at once with Promise.all.

3 · Event Loop Demo

Contains 2 timers, 2 promise callbacks and 1 async function. Prediction written before running it — press the button to see the real order.
